# G1 Awakening for iOS — v0.17.0-r1

**Development Preview · Native ARM64 · iPhone & iPad · by iammrmikeman**

Download **G1-Awakening-iOS-v0.17.0-r1.ipa** from the release assets to install the complete game package. The source archive is optional and is not an installer.

## Included

The Build 017 native runtime, Classic and Modern presentation, supported original 3D tactical forms and authored motion, the supplied replacement intro, and the completed Pass01 mapped UI/forest-grass replacements. The later Block 1 asset checkpoint and visual map extensions are not silently included in this resource revision.

## Installation

Compiled minimum: **iOS/iPadOS 15.0**, ARM64/Metal hardware. This package retains the existing AppSync-oriented ad-hoc executable signature. Use a compatible jailbreak with AppSync Unified and Filza, or standard TrollStore only on its supported OS/device combinations. Stock-device installation through Sideloadly requires developer re-signing; that exact route remains unverified for this candidate. See the [installation guide](https://github.com/iammrmikemanmods/G1-Awakening-IOS/blob/main/docs/INSTALL.md).

Back up saves before upgrading. Do not uninstall the previous version merely to resolve a signing error. The Home Screen name is **G1 Awakening**. Internal app version stays **0.17.0 / build 17**; **r1** identifies the resource revision. The existing bundle identifier is preserved for save/update continuity.

## Integrity and source

The IPA is a byte-identical public-name copy of the verified 017R1 package, not a new compile or re-sign.

```
File: G1-Awakening-iOS-v0.17.0-r1.ipa
Size: 37,688,499 bytes
SHA-256: b035acfe0c08aafa715c54f60a59423191046c271328abbca4cd72689dfaed46
```

The matching Source ZIP includes runtime source, the resource packaging script, tests and recovery instructions. Check the included SHA256SUMS file before re-signing; re-signing changes the checksum.

## Preview limitations

This is not a finished remaster or a certified full-campaign release. Exact physical-device validation of this package, per-character animation polish, remaining UI/effect fidelity, the full asset library and legacy iOS support remain open. The available native XR screenshots show the earlier UI-restoration checkpoint, not this release's final appearance. No concept images or original-PC frames are presented as current iOS screenshots.
