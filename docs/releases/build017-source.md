# Build 017 — native source and code preview

A traceable development snapshot of **Transformers: G1 Awakening iOS**, by **iammrmikeman**.

**This release is source/native-code only. It is not a complete playable IPA and contains no original game archive, original media, remastered PNG pack or user saves.** Read the attached asset names before installing anything.

## Included

- Source pinned to `be203a911bc26313615ea450758413e5c9cf6462`.
- The previously verified native ARM64 code/evidence artifact, if uploaded with this release.
- SHA-256 checksums for the attached archives.

The native development line includes restored original gameplay systems, adaptive shared UI, Classic/Modern modes, Modern supersampling, supported 3D tactical forms, authored motion and optional source-keyed clean textures. New artwork and exact device presentation remain under development.

## Evidence and limits

The recorded Build 017 run `40634462289` passed 72 Linux and 72 Apple native tests, ARM64/iPhoneOS and shader compilation, plus hosted synthetic Metal checks. Publishing these files does not rerun or extend those tests. Earlier XR screenshots demonstrate earlier native execution; they are not current-release screenshots.

The compiled target is iOS/iPadOS 15.0+ on ARM64/Metal hardware. Other OS/device combinations and this exact package's TrollStore/Sideloadly routes remain unverified. Authored transformations are approximations and unsupported states can use sprites. Terrain extensions and the entire new art library are not complete.

## Full game package

The later **017R1 resource revision** keeps this executable and adds the maintainer-supplied intro and completed Pass01 artwork.
